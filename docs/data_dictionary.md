# Data dictionary

**Project:** CYPLAN 101, *Identifying Flood Risk Reduction from Marshes* (San Francisco Bay Area).

**Status:** Spatial cleaning is implemented in `src/clean_data.py`; research analysis has not begun. The BHM preparation output selects exact `Level4 = Tidal Marsh` values. Recognized CRSs are transformed to EPSG:26910; Flood Explorer's unresolved source WKT is preserved. Nine-county membership is checked only from explicit source county fields; unmatched values are retained for review. Layers without a county field are not spatially filtered because no county boundary/crosswalk is available. Prepared GeoPackages are under `data/processed/` and rebuild from raw sources. The entries below describe verified, potentially relevant source layers. Counts, schemas, sample values, bounds, and inspection errors are in [`outputs/tables/data_inventory.json`](../outputs/tables/data_inventory.json), generated by `src/inspect_data.py`. Types below are Pyogrio field types. Field definitions are only stated where verified; labels inferred from names are marked unverified.

## Baylands Habitat Map 2020 (BHM2020)

- **Source:** `data/raw/BHM2020/BHM2020_v1_3/BHM2020_v1_3.gdb`; SFEI Baylands Habitat Map 2020 v1.3 release.
- **Represents:** Classified Baylands habitat polygons. Main layer `BaylandsHabitatMap2020_v1_3`: 168,511 multipolygons, EPSG:26910. Boundary layer has one multipolygon.
- **Relevant fields:** `Level2`, `Level3`, `Level4`, `Level5`, `DetailedHabitatClassification`, `Status` (text); `Project_ID` (int32). Observed sample labels include `Estuarine`, `Intertidal, Full Tidal Connection`, and `Beach`; the authoritative tidal-marsh class selection and status meanings are **unverified**. `Project_ID` was null in the inspected sample; dataset-wide completeness/uniqueness is **unknown**.
- **Units/limits:** No units apply to class fields. Geometry units follow CRS; confirm before measurement. The archive copy at `data/raw/BHM2020/BHM2020_v1_3.zip` was not opened.

## Baylands Resilience Metrics v1.2

- **Source:** `data/raw/Baylands_Resilience_Metrics_v1_2.gdb`; layer `Analysis_Units_2020_v1_2`.
- **Represents:** 1,968 multipolygon analysis units, EPSG:6414. Sample labels include `Unit_Type=Marsh Unit`, `Majority_Class=Low Marsh`, and `Tidal_Connectivity=Fully Tidal`.
- **Relevant fields:** `Unit_Type`, `OLU_Name`, `OLU_ID` (int16), `Subembayment_Name`, `Subembayment_ID` (int16), `Majority_Class`, `Tidal_Connectivity`; `MEAN_RANGE_Marsh_Width`, `MEAN_MEAN_Marsh_Width_Needed`, `MEAN_MIN_Output_Wave_Height`, `MEAN_MAX_Output_Wave_Height` (float64).
- **Units/limits:** A sampled `MEAN_RANGE_Marsh_Width` is 260.24, but width and wave-height units, vertical datum, and detailed metric definitions are **unverified**. EPSG:6414 is the inspected CRS; confirm its suitability and transformation for the analysis.

## Community Vulnerability (BCDC 2020)

- **Source:** `data/raw/CommunityVulnerability.gdb`; layer `CommunityVulnerability_BCDC_2020`.
- **Represents:** 4,750 multipolygon community areas, described in sample `NAME` values as Census block groups; EPSG:26910.
- **Relevant fields:** `GEOID`, `TRACTID`, `NAME` (text); `estimate_totPop` (float64); `socVulnRank` (text), `socVuln70`, `socVuln90` (float64); `SUM_res_units_*_exp_*` and `SUM_job_spaces_*_exp_*` (float64) for named year/scenario suffixes.
- **Verified sample / limits:** Sample `GEOID` is a 12-character block-group identifier; `estimate_totPop=3115`; `socVulnRank=Low social vulnerability`. Population reference year, estimate units/source, vulnerability thresholds, and exposure scenario suffix definitions require dataset documentation. Exposure fields are aggregated residential-unit/job-space values, not verified resident counts. No explicit Equity Priority Community indicator has been verified.

## SF Bay Shore Inventory, SFEI 2016

- **Source:** `data/raw/SFBayShoreInventory_SFEI_2016_0 (1)/ESRI ArcGIS/SFBayShoreInventory__SFEI_2016.gdb`.
- **Represents:** `San_Francisco_Bay_Shore_Inventory` (15,782 multilines) and `San_Francisco_Bay_Shore_Inventory__100ft_segments_with_elevation` (167,565 multilines); both EPSG:3310.
- **Relevant fields:** `Segment_ID` (int32); `Class`, `Transportation_Type`, `Fortified`, `Frontage`, `Bayshore_Defense`, `Geographic_County`, ownership/agency fields (text); elevation layer also has `Z_Min`, `Z_Max`, `Z_Mean` (float64). Sample literal values include `Class=Berm`, `Fortified=No`, `Frontage=Beach`, `Bayshore_Defense=First line of shoreline defense`.
- **Units/limits:** Elevation units and vertical datum, field codebooks, segment-ID uniqueness, and comparability between the two layers are **unverified**.

## SF Bay Shore Inventory, SFEI BHM2020 update

- **Source:** `data/raw/SFEI_BayShoreInventory_BHM2020update_v1/SFEI_BayShoreInventory_BHM2020update_v1.gdb`; layer `SFEI_BayShoreInventory_BHM2020update_v1`.
- **Represents:** 10,762 shoreline multilines, EPSG:26910.
- **Relevant fields:** `Segment_ID` (int32); `Class`, `Fortified`, `Frontage`, `Bayshore_D` (text); `BCB_Eng` (int32); `Shape_Leng`, `Shape_Length` (float64). Sample literals include `Berm`, `No`, `Beach`, and `First line of shoreline defense` for the corresponding class/fortification/frontage/`Bayshore_D` fields.
- **Units/limits:** Meaning/coding of `Bayshore_D` and `BCB_Eng`, length units, and ID comparability with SFEI 2016 are **unverified**. Do not combine releases without reconciling coverage and identifiers.

## Vulnerable Communities, BCDC Flood Explorer 2020

- **Source:** `data/raw/VulnerableCommunities/VulnerableCommunities_Consequences_FloodExplorer_BCDC_2020.gdb`.
- **Layers:** Ten `VC_SocialVulnerability_*` layers (777 multipolygons each) and ten `VC_ContaminationVulnerability_*` layers (309 each); suffixes are `12, 24, 36, 48, 52, 66, 77, 84, 96, 108`. Stored CRS describes UTM Zone 10N, but EPSG resolution failed.
- **Relevant fields:** `GEOID` (text); `socVlnRank`, `contamRank`, `TWL`, `Class`, `Type`, `CountyName`, `CityName` (text); `Social_Sensitivity_Class`, `Contam_Sensitivity_Class`, `HS_*`, `SUM_res_units_2010`, `SUM_res_units_2040`, `SUM_job_spaces_2010`, `SUM_job_spaces_2040` (integer/float fields; see JSON for each layer's types).
- **Verified sample / limits:** Sample class labels include `Highest social vulnerability` and `Vulnerable Communities`; `TWL` matches the layer suffix in inspected records. Meanings/units of `TWL`, `HS_*`, and the suffix codes are **unverified**. These are community consequence polygons, not verified flood extent/depth surfaces. Resolve CRS/datum before spatial joins.
